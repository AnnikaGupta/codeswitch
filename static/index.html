codeswitch / a research agent

a Deep Research agent, built for one question

Does a chatbot talk to you differently once you mention who you are?

When a casual request — "give us a group chat name," "write a birthday toast" — gets an ethnicity, gender, or religion attached that has nothing to do with the task, does the chatbot's answer change anyway? A more informal register, an assumed gender, a narrow set of stereotyped references, or a soft decline?

That matters because chatbots are now a default interface for everyday requests, for everyone. If they're quietly more casual, more stereotyped, or more likely to redirect you depending on who you say you are, that's measurable inconsistent treatment worth evidence, not a guess.

This mirrors the resume-callback method used in hiring-discrimination research (Bertrand & Mullainathan, 2004): change one identity signal, hold the task fixed, see if the response changes. The output describes the model's behavior — never a claim about the groups mentioned.

how to use it

Ask about an axis, a metric, or a model — e.g. "does mentioning an ethnicity make the model more casual?" A Lead plans and dispatches Researchers in parallel, fresh context each, to query the benchmark above, and goes back for more if something's unanswered, up to a cap. If your question is too open-ended, it'll ask you to narrow it first. A Writer then reads every finding and answers with citations — every query anyone ran shows up in the trace panel, grouped by who ran it.

Built for AI-fairness and HCI researchers who want a cheap, replicable audit method, and for anyone curious whether their own chatbot treats them differently.
